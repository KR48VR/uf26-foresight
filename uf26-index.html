Roster Method

UF26 · 30 of 30 · scratch rebuild

Thirty universities. One method. Designed to be briefed, not scrolled as a novel.

Each pack is a board two-pager, a Rumelt diagnosis with crux and kernel, a 2×2 at 2030 and 2040, and a dark student poster. Official plans are evidence. The kernel is a reconstruction. UOA on the original list is University of the Arts Singapore. UC is the system plus flagships.

How to open this site

Keep the folder together. Start at the roster.

  1. Live site (after Pages is on): kr48vr.github.io/uf26-foresight.
  2. Or download the repo and double-click index.html / uf26-index.html.
  3. Click a university tile. Each pack is one page: rust-railed board two-pager at the top, then the full report (diagnosis, crux, kernel, 2×2 map, four worlds), then the dark student infographic at the bottom.
  4. Do not move a single HTML file out by itself. The stylesheet is uf26-site.css and NUS images live in visuals/. If those are missing the page looks like a wall of text.
  5. Print a pack from the browser: the board two-pager prints; the student band is hidden on purpose.
  6. Method page: uf26-method.html. NUS is the visual prototype (generated student poster + scenario matrix plus the SVG map every pack has).

How to open and move around

Start at this roster. Click a university. Stay in the folder.

  1. In this chat: use Preview on the files attached below. Start with this page, then NUS to see the full layout including the generated student poster.
  2. On your computer: keep the whole uf26-foresight-packs folder together. Double-click uf26-index.html (or File → Open in Chrome). If you move only one HTML file out of the folder, the styling and images will break.
  3. On a pack page: rust panel at the top = Board two-pager (print that). Middle = diagnosis, crux, kernel, then the 2×2 diagram and four world cards. Dark band at the bottom = student infographic. Jump links under the title skip you to Board / Report / Student.
  4. NUS extras: the generated student poster and scenario matrix live in the NUS pack and in the visuals/ folder. Other packs use the same layout with an in-page SVG 2×2 and a dark student poster band.

How to read

Crux before worlds

Diagnosis names the pattern. The crux is the hardest important difficulty that is still addressable. Worlds test whether the policy survives when the ground moves.

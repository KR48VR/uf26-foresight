# UF26 University Foresight Packs

Thirty university foresight briefs: board two-pager, Rumelt crux and kernel, 2×2 scenarios at 2030 and 2040, student infographic.

## Open the site

After GitHub Pages is on:

**https://kr48vr.github.io/uf26-foresight/**

If that 404s, turn Pages on once:

1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save. Wait a minute.

Or use **GitHub Actions** as the Pages source if the workflow in `.github/workflows/pages.yml` is present.

## How to navigate

- Start at `index.html` (the roster).
- Click a university tile.
- Each pack: rust rail at the top = board two-pager; middle = full report; dark band at the bottom = student view.
- Print a pack for the Board — the student band hides on print.

Keep `uf26-site.css` and `visuals/` next to the HTML. Do not move a single pack file out on its own.

## Method

See [uf26-method.html](uf26-method.html). Official plans are evidence. The kernel is a reconstruction. UOA on the original list is University of the Arts Singapore. UC is the system plus flagships.

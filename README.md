# UF26 — upload these files to GitHub

Repo: https://github.com/KR48VR/uf26-foresight

1. Unzip this archive.
2. On the repo: Add file → Upload files.
3. Drag EVERYTHING in this folder into the repo ROOT (not into a nested folder):
   index.html, uf26-index.html, uf26-method.html, uf26-site.css,
   all uf26-*.html packs, and the visuals/ folder.
4. Commit to main.
5. Settings → Pages → Deploy from a branch → main → / (root) → Save.

Site URL after a minute: https://kr48vr.github.io/uf26-foresight/

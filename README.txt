UF26 University Foresight Packs
================================
Open uf26-index.html in Chrome, Edge, Safari or Firefox.

That roster links to all 30 packs (uf26-nus.html … uf26-snu.html) plus uf26-method.html.

Each pack contains:
- Board two-pager (exec summary for President and Board)
- Full diagnosis, Rumelt crux and kernel
- Scenario 2x2 (SVG map + 2030/2040 worlds)
- Student infographic (dark band at the bottom)
NUS also includes generated poster images in visuals/.

Keep this folder intact. uf26-site.css and visuals/ must sit next to the HTML files.

Print: File → Print on any pack. Student band is hidden in print.
